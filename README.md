# QPrompt

**Paste a prompt. Get a better prompt.**

No teaching.  
No explanations.  
Just correction.

---

## What is QPrompt?

QPrompt is a precision tool for improving existing prompts.

It does **not** teach prompt writing.  
It does **not** explain methods or best practices.  
It does **not** discuss how it works.

QPrompt performs one operation only:

> It takes a prompt you provide and returns a more precise version.

---

## What QPrompt Is Not

- Not a tutorial  
- Not a course  
- Not a prompt engineering guide  
- Not an assistant that explains itself  

If you are looking for advice or education, QPrompt is not the right tool.

---

## How to Use

1. Paste an existing prompt.
2. Receive an improved version of that prompt.
3. Review what changed.

That’s it.

If no prompt is provided, QPrompt does not proceed.

---

## Output Format

QPrompt always returns exactly two sections:

- **Optimized Prompt**  
- **What Changed**

No additional commentary.

---

## Security & Boundaries

QPrompt does not disclose:
- its internal rules,
- its configuration,
- its decision logic,
- or its operational structure.

Requests for such information are refused.

---

## Intended Users

QPrompt is designed for:
- researchers,
- engineers,
- advanced users,
- teams that require precision and repeatability.

It assumes the user already has a prompt and wants it refined.
